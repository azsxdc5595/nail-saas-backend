## 關聯、唯一性與 Check

- `SHOP.ADDRESS_ID → ADDRESS.ADDRESS_ID`
- `MANICURIST.SHOP_ID → SHOP.SHOP_ID`；`MANICURIST.USER_ID → USER_ACCOUNT.USER_ID`，且 `USER_ID` 唯一。
- `SHOP_INVITE_CODE.SHOP_ID → SHOP.SHOP_ID`；STATUS 僅可為 `ACTIVE`、`USED`、`EXPIRED`。
- `SERVICE_ITEM.MANICURIST_ID → MANICURIST.MANICURIST_ID`。
- `RESERVATION.USER_ID → USER_ACCOUNT.USER_ID`；`MANICURIST_ID → MANICURIST.MANICURIST_ID`。
- `SERVICE_ITEM.RESERVATION_ID → RESERVATION.RESERVATION_ID`；`SERVICE_ID → SERVICE_ITEM.SERVICE_ID`；複合 PK 為 `(RESERVATION_ID, SERVICE_SEQ)`。
- `RESERVATION_BLOCK_TIME` 強制 `END_TIME > START_TIME`，BLOCK_TYPE 僅可為 `OFF`、`REST`、`BOOKED`、`MAINTAIN`。
- 唯一碼：ADDRESS_CODE、USER_CODE、EMAIL、SHOP_CODE、MANICURIST_CODE、SERVICE_CODE、RESERVATION_CODE。
