# 1. Purpose

定義 Nail SaaS 專案各階段開發目標、功能範圍及交付內容。

Roadmap 作為產品開發依據，提供團隊了解目前開發進度與後續規劃，不代表實際 Sprint 排程。

---

# 2. Development Strategy

本專案採 MVP（Minimum Viable Product）方式逐步開發。

原則如下：

- 先完成核心商業流程
- 優先完成預約流程
- 功能完成後再提升使用者體驗
- 採持續迭代方式新增功能

# 4. Phase 1 - Core Foundation

## Goal

建立系統基礎架構，完成店家、美甲師與作品管理。

## Modules

- Authentication
- Shop Management
- Manicurist
- Portfolio
- Service Item

## Deliverables

- 使用者登入
- JWT Authentication
- 權限管理
- 店家管理
- 美甲師管理
- 作品管理
- 服務項目管理
